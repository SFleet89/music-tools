# Filename Scanner

Scans your organized music library and flags filenames that look messy or malformed — underscores instead of spaces, all caps, inconsistent dash spacing, dots as separators, and more. Tracks your cleanup progress across multiple scans over time.

Nothing is renamed. This script is completely read-only.

---

## How it works

Every music file is checked against a set of rules. Flagged files are grouped by folder in the console and saved to a set of CSVs — one per issue type — so you can tackle one problem at a time in your rename utility.

Files matching your skip list are excluded from all reports and logged separately.

---

## Requirements

No dependencies beyond Python's standard library.

---

## Setup

1. Open `scan_music_filenames.py` and set the three path constants near the top:
   ```python
   DEFAULT_FOLDER = r"C:\Music\Organized"
   REPORTS_FOLDER = r"C:\Music\tools\filename_scanner\reports"
   SKIP_LIST_FILE = r"C:\Music\tools\filename_scanner\scan_skip_list.txt"
   ```

2. Edit `scan_skip_list.txt` with any artists or patterns to exclude.

3. Run:
   ```
   python scan_music_filenames.py
   ```

---

## Usage

```
python scan_music_filenames.py                      # scan default folder
python scan_music_filenames.py --path "C:\Music"    # scan a specific folder
python scan_music_filenames.py --summary            # folder list only
python scan_music_filenames.py --issues             # add issue breakdown
```

## What gets flagged

| Issue | Example |
|---|---|
| Underscores instead of spaces | `01-artist_title.mp3` |
| Brackets with underscores | `01 - Something (Live_1975).mp3` |
| Double spaces | `01  Alicia Keys - No One.mp3` |
| Leading/trailing junk | `Apashe - Song Title .mp3` |
| Dots as separators | `02.Massive.Attack.One.Love.mp3` |
| Inconsistent dash spacing | `Amethystium -01- Llona.mp3` |
| All caps | `109 RUNNING THROUGH THE CYBER WORLD.mp3` |
| Starts with lowercase | `01-artist-title.mp3` |
| Mixed separators | `01-Artist_Title.mp3` |

Artist name dots (`Will.i.am`, `B.o.B`), acronym titles (`M.M.I.X`, `U.F.O`), and common clean formats are not flagged.

---

## Skip list

`scan_skip_list.txt` — one pattern per line. Any file whose name or folder path contains the pattern is excluded from all issue reports.

```
# Intentional lowercase artist names
ilan bluestone

# All-caps OST folders
rockman exe

# Folder-level skip
anime
```

---

## Viewers

**`scan_report_viewer.html`** — drop any scan CSV to review flagged files. Filter by issue type, search, sort, and build your skip list queue directly in the browser. The skip list queue is saved between sessions.

**`scan_compare_viewer.html`** — drop two scan CSVs (older left, newer right) to see what's been fixed, what's new, and what's still outstanding.

**`scan_progress_viewer.html`** — drop a `scan_progress_*.csv` (generated by `scan_progress.py`) to see a trend chart of flagged files over time and a per-issue-type progress breakdown.

---

## Progress tracking

```
python scan_progress.py                      # analyse all scan reports
python scan_progress.py --first-vs-last      # first vs latest only
```
