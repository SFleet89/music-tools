# Music Duplicate Undo

Restores files moved by `find_music_duplicates.py` back to their original locations. Reads any CSV report generated by the main script and reverses the moves — safely, with a dry-run option and full conflict handling.

Nothing is ever deleted. If a file can't be restored (missing, or something already exists at the destination), it is skipped with a clear explanation.

---

## Requirements

No additional dependencies — uses only Python standard library.

---

## Usage

```
python undo_duplicates.py <path_to_csv_report> [options]
```

**Options:**

| Flag | Description |
|---|---|
| `--dry-run` | Preview what would be restored without moving anything |
| `--list` | Full summary of what the CSV contains — files, categories, methods |
| `--list-categories` | Print all categories and match methods found in the CSV and exit |
| `--filter-category CAT` | Only restore files from a specific category |
| `--filter-method METHOD` | Only restore files matched by a specific method |

**Examples:**

```
# Undo everything from a run
python undo_duplicates.py "C:\Music\Duplicates\music_report_20260302_120000.csv"

# Preview only
python undo_duplicates.py "C:\Music\Duplicates\music_report_20260302_120000.csv" --dry-run

# See a full summary of what the CSV contains before undoing
python undo_duplicates.py "C:\Music\Duplicates\music_report_20260302_120000.csv" --list

# See what categories and methods are in the report
python undo_duplicates.py "C:\Music\Duplicates\music_report_20260302_120000.csv" --list-categories

# Only undo exact matches
python undo_duplicates.py "C:\Music\Duplicates\music_report_20260302_120000.csv" --filter-category "Exact Match"

# Only undo fingerprint-matched duplicates
python undo_duplicates.py "C:\Music\Duplicates\music_report_20260302_120000.csv" --filter-method "audio fingerprint"

# Preview only fingerprint matches before undoing
python undo_duplicates.py "C:\Music\Duplicates\music_report_20260302_120000.csv" --filter-method "audio fingerprint" --dry-run

# Combine filters
python undo_duplicates.py "C:\Music\Duplicates\music_report_20260302_120000.csv" --filter-category "DUPLICATE" --filter-method "audio fingerprint"
```

---

## Recommended workflow

Before running undo, use `--list` to review what the CSV contains:

```
# Step 1 — see what would be restored
python undo_duplicates.py "music_report_...csv" --list

# Step 2 — dry run to confirm
python undo_duplicates.py "music_report_...csv" --dry-run

# Step 3 — undo for real
python undo_duplicates.py "music_report_...csv"
```

Or drop the live report into `undo_report_viewer.html` to browse what was moved visually before running the script.

---

## How it works

The script reads the CSV report and looks for rows where a file was actually moved (actions starting with `Moved to` or `Auto-moved`). Dry-run rows from the original run are automatically ignored.

For each moved file it:
1. Checks the file still exists at its destination
2. Checks nothing already exists at the original location
3. Recreates any missing parent folders
4. Moves the file back

If either check fails, the file is skipped and the reason is printed.

---

## Filter categories

Use `--list-categories` to see exactly what values are in a given report. Common values are:

| Category | Description |
|---|---|
| `Exact Match` | Files that were auto-moved as confirmed exact duplicates |
| `DUPLICATE` | Files selected for move during the Standard Duplicates review |
| `BETTER QUALITY` | Files selected for move during the Higher Quality review |

Older reports may use `Standard Duplicate` or `Higher Quality Match` — these are also accepted.

---

## Report viewer

`undo_report_viewer.html` is a standalone browser-based viewer for live run reports. Drop any `music_report_*_live_*.csv` onto the page to see everything that was moved — category, match method, original location, and current location — before running the undo script.

A **Copy undo command** button in the top right copies the exact command for the loaded file to your clipboard.

---

## Compatibility

Works with CSV reports from `find_music_duplicates.py` v3.0 and later. The `Match Method` and `Why Not Exact` columns present in v3.1+ reports are used for filtering but not required for the restore itself.

---

## Notes

- The original CSV report is never modified
- Subfolders are recreated automatically if they no longer exist
- Running undo multiple times on the same report is safe — already-restored files will be skipped on subsequent runs
